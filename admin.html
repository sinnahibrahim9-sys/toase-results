Toase SHS Portal Admin: student import

Admin sign in

Use the email and password you created in Supabase.

1. Choose the student list

A CSV file with the columns full_name and class. A student_id column is optional; leave it out and IDs are created for you.

2. Create the accounts

Each student gets a Student ID and a random 6-digit PIN. Keep this page open until it finishes.

3. Save the login list

PINs are shown only now and cannot be looked up later. Download the file, print the slips, then delete the file from your phone or computer.
